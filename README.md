## Локальная установка и запуск

### Требования
- Node.js >= 16
- npm >= 8

### Установка
Клонируйте репозиторий и установите зависимости:

# Установка зависимостей
make install

# Режим разработки
make dev

# Сборка для продакшена
make build

# Запуск продакшен-сборки
make start
